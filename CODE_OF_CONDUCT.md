# Code of conduct

## The short version

Be decent. Argue about code, not about people.

## What we expect

- Assume the other person is trying to build something good.
- Critique the work: the design, the tradeoff, the bug. Not the author.
- Accept that a maintainer may say no to a change that is perfectly good code
  but wrong for this project. The rules in [CONTRIBUTING.md](CONTRIBUTING.md)
  come from the product, not from taste.
- Ask before assuming bad faith. Most disagreements are missing context.

## What is not acceptable

Harassment, personal attacks, discriminatory language, sustained disruption of
discussion, publishing someone's private information, or unwelcome attention of
any kind. This applies in issues, pull requests, commit messages and any other
project space.

## Enforcement

Report a problem through GitHub's private reporting on this repository, or by
contacting a maintainer directly. Reports stay confidential.

Maintainers may edit or remove contributions that violate this document, and may
block accounts. A first incident usually gets a warning; behaviour that
continues after one does not.

## Scope

Project spaces, and public spaces when someone is representing the project.
